# Screenshot instructions

1. Import workflow.json into a clean n8n instance (current version).
2. Do not connect real credentials. Nodes may show the "credentials needed" warning; that is fine. Never show a real phone number, token or spreadsheet id.
3. Zoom to fit (shortcut 1), hide the minimap, light theme, window about 1600x900.
4. Keep the overview sticky note (yellow, top left) and the section notes readable.
5. Frame the full canvas including both sticky notes.
6. Save as PNG under 2 MB and upload it in the creator hub with the submission.
